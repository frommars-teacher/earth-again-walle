# 작은 새싹, 푸른 지구

초등학교 4학년 영화 월-E 환경 수업 웹앱입니다.

## 실행

index.html을 브라우저로 열거나, Node.js 설치 후 `node server.cjs`를 실행하고 http://localhost:4173 에 접속하세요.

## 활동

- 4차시: 줄거리와 감상 구간, 객관식 12문항, 생각 쓰기 12문항
- 주관식 힌트와 문장 틀, 실천 약속 2개
- Lv.1~20 성장, 새싹 키우기, 배지와 환경 보너스 놀이
- 효과음과 음소거, 기록 내려받기와 인쇄

답안은 현재 브라우저에만 저장됩니다. 서버에 전송하지 않습니다. 같은 기기와 브라우저 주소에서 이어할 수 있습니다.

영화 영상은 포함하지 않습니다. 교사가 별도로 재생해 주세요.
